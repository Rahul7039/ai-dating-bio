## The bio

> I read your entire chat history before our first date, so I already know you type 'haha' when you're mad and 'k' when you're done.

130 characters — a dating-app bio from an AI that already knows you a little too well. The laugh lands on a specific, instantly recognisable texting tell, and the punch ("'k' when you're done") closes the line.

## How to run

```bash
python3 main.py
```

This writes the bio line — and only that line — to `/output/entry.txt`.

## How it works

`main.py` holds the chosen line as a single constant and writes it verbatim to `/output/entry.txt` (creating `/output` if needed), then prints it. No network, no dependencies, no extra text in the output file.
